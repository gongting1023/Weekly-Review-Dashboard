# 每周复盘工作台 Weekly Review Dashboard

一个**纯前端、零依赖、单文件**的个人每周复盘工作台。打开 `index.html` 即用，无需安装、无需联网、无需账号。

> 设计主题：奶白底色 · 深蓝主色 · 成长绿点缀

## 功能一览

### 📋 六大核心页面
| 页面 | 用途 |
|---|---|
| 首页 | 本周概览数据卡、今日要处理、快捷入口 |
| 本周数据 | 录入任务/计划/亮点/问题/经验/本周目标，工作·生活双栏切换 |
| 完成清单 | 已完成事项汇总，完成率追踪 |
| 亮点问题 | 本周亮点与问题记录，问题支持影响分级 |
| 经验沉淀 | 可复用的经验教训，形成个人方法论 |
| 下周计划 | 计划排期、优先级（P0/P1/P2）、进度跟踪 |

### ⚡ 附加能力
- **工作 / 生活双栏** — 所有记录按领域分类，互不混杂
- **周能量评分** — 每周 1-10 分主观能量值 + 备注，自动生成趋势折线图
- **季度回顾** — 自动聚合一个季度 13 周的全部记录，一键生成回顾草稿、复制为文本
- **未完成迁移** — 上周没做完的任务一键顺延到下周（保留领域归属与备注）
- **周归档** — 复盘完的一周可归档，保持列表清爽
- **自定义分类** — 内置 6 个分类不够用？分类下拉里直接新增 / 改名 / 删除（实时生效，删除不丢历史）
- **数据安全** — 导出 JSON 备份 / 导入恢复 / 清空二次确认

### 📱 移动端适配
- 窄屏自动单列布局，底部 Tab 导航，侧栏变抽屉
- 按钮点击区域 ≥ 44px，输入框字号 ≥ 16px（防 iOS 缩放）
- 可「添加到主屏幕」当 App 使用

## 快速开始

**方式一：直接打开**

下载 `index.html`，双击用浏览器打开即可。

**方式二：在线使用（GitHub Pages）**

1. 仓库 Settings → Pages → Source 选择 `main` 分支
2. 访问 `https://gongting1023.github.io/Weekly-Review-Dashboard/`

## 数据存储说明

- 所有数据保存在**浏览器 localStorage** 中，不上传任何服务器，刷新/关闭不丢失
- 旧版本数据自动兼容迁移（补齐 `domain`、`energy` 等新字段）
- **注意**：localStorage 跟随浏览器和域名，换浏览器/换设备不会自动同步——跨设备请用「导出 JSON → 另一端导入」
- 建议积累 30 条以上数据时导出一份 JSON 备份

## 技术特点

- **单文件 HTML**：CSS / JS / 图标 / 图表全部内联，零外部依赖，离线可用
- **全手绘 SVG**：进度环、折线图、热力日历、全部图标均为内联 SVG
- **函数调用图无环**：渲染函数严格单向调用，统一 `refreshAll()` 调度，杜绝递归环路
- **用户输入全转义**：所有动态拼接经过 `esc()` 处理，防注入
